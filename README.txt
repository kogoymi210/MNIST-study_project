--------------------------------------------------------------------------------
3. АНСАМБЛЬ
--------------------------------------------------------------------------------

Метод: soft voting с равными весами.
  1. Каждая из 5 моделей переводится в режим eval (Dropout выключен,
     BatchNorm использует накопленную статистику).
  2. Для батча каждая модель выдаёт логиты -> softmax -> вероятности классов.
  3. Вероятности пяти моделей усредняются.
  4. Ответ ансамбля - класс с максимальной средней вероятностью (argmax).

Модели с разной архитектурой и разными seed ошибаются
на разных картинках, и усреднение вероятностей сглаживает отдельные ошибки.
Ансамбль сократил число ошибок на test с 62 (лучшая модель) до 47.

--------------------------------------------------------------------------------
4. АРХИТЕКТУРА МОДЕЛЕЙ
--------------------------------------------------------------------------------

Все модели получают вход (N, 1, 28, 28) и выдают 10 логитов. Активация - ReLU.
Размеры после свёрток считаются по формуле:
  Out = (In + 2·padding - kernel) / stride + 1

Model_Linear - полносвязная сеть, 6 слоёв (~628 тыс. параметров)
  Flatten(784) -> 512 -> 320 -> 150 -> 75 -> 24 -> 10

Model_Conv_1: 2 свёртки + MaxPool (~147 тыс. параметров)
  Conv 5×5, 1->16         28×28 -> 24×24
  MaxPool 2                 	-> 12×12
  Conv 5×5, 16->32   	        -> 8×8
  MaxPool 2             	-> 4×4      (32·4·4 = 512)
  Linear 512 -> 256 -> 10

Model_Conv_2 - 3 свёртки с padding + Dropout (~182 тыс. параметров)
  Conv 5×5 pad 2,  1->16  28×28 -> 28×28, Dropout2d(0.2)
  MaxPool 2                     -> 14×14
  Conv 5×5 pad 2, 16->32        -> 14×14, Dropout2d(0.2)
  MaxPool 2                     -> 7×7
  Conv 3×3 stride 2, 32->64     -> 3×3, Dropout2d(0.2)   (64·3·3 = 576)
  Linear 576 -> 256 -> Dropout(0.3) -> 10

Model_Conv_3 - 4 свёртки, BatchNorm, без пулинга (~95 тыс. параметров)
  Каждый блок: Conv -> BatchNorm2d -> ReLU -> Dropout2d(0.3) X 4
  Conv 5×5, 1->16         28×28 -> 24×24
  Conv 3×3 stride 2, 16->32     -> 11×11
  Conv 3×3, 32->64              -> 9×9
  Conv 3×3 stride 2, 64->32     -> 4×4   (32·4·4 = 512)
  Linear 512 -> 100 -> Dropout(0.3) -> 10
  Уменьшение размера делают свёртки со stride 2 вместо MaxPool.

Model_Conv_4 — как Conv_3, но шире последний блок (~164 тыс. параметров)
  Последняя свёртка 64->64 вместо 64->32  (64·4·4 = 1024)
  Linear 1024 -> 100 -> Dropout(0.3) -> 10



--------------------------------------------------------------------------------
5. ПАЙПЛАЙН
--------------------------------------------------------------------------------

  1. Загрузка CSV в NumPy (np.loadtxt), отделение меток от пикселей.
  2. Нормализация пикселей в диапазон 0–1; пиксели -> float32, метки -> int64.
  3. Разбиение на train / val / test.
  4. Перевод в тензоры и view в форму (N, 1, 28, 28).
  5. Класс MyDataset + DataLoader внутри функции обучения 
	(batch_size=256, num_workers=2(в рамках colab)).
  6. Обучение на GPU (выбор device имеется) с аугментацией Kornia над батчем.
  7. Валидация каждую эпоху, early stopping + dynamic learning rate.
  8. Оценка на test, графики обучения, визуализация предсказаний, ансамбль.

--------------------------------------------------------------------------------
6. ФУНКЦИИ И ВОЗМОЖНОСТИ
--------------------------------------------------------------------------------

seed_everything(seed=22)
  Фиксирует seed для random, NumPy и PyTorch (CPU и CUDA). Вызывается в начале
  train_model до создания модели для воспроизводимости весов.

MyDataset(data, target, transform=None)
  хранит пиксели и таргеты раздельно (+у них разные типы),

aug - аугментация Kornia (только для train, на GPU, над всем батчем):
  - RandomAffine(degrees=15, p=1.0)       — поворот до +-15°
  - RandomPerspective(0.5, p=0.5)         — перспективное искажение
  - RandomErasing(scale=0.02–0.33, p=0.5) — стирание прямоугольного участка
  яркость и контраст почти не влияют на метрики

train_model(class_model,. . .) — универсальная функция обучения и теста
  Параметры:
    class_model      класс модели или уже готовый объект nn.Module
                     (проверка через isinstance: класс создаётся, готовая
                     модель используется как есть, то можно только тестировать)
    learning_rate    начальный lr (по умолчанию 0.001)
    epochs           число эпох (по умолчанию 1)
    train_default
    val_default
    test_default     тензоры данных формы (N, 1, 28, 28)
    train, test      флаги: обучать и/или тестировать (отдельно)
    early_stopping   ранняя остановка по val_accuracy (по умолчанию True)
    patience         эпох без улучшения до остановки (по умолчанию 10)
    dynamic_lr       снижение lr при застое val_loss 
					(меняет optimizer.param_groups)
    patience_lr      эпох без улучшения val_loss до снижения lr (5)
    diff_lr          множитель lr при снижении (по умолчанию 0.5)
    seed             seed для воспроизводимости (по умолчанию 22)

  Что делает:
    - автоматически выбирает device (cuda, если доступна);
    - оптимизатор Adam, функция потерь CrossEntropyLoss;
    - каждую эпоху считает train loss/accuracy, val loss/accuracy и время;
    - лучшая по val модель сохраняется через copy.deepcopy и возвращается
      в конце (не последняя);
    - ведёт словарь history: epoch, train_loss, train_accuracy, val_loss,
      val_accuracy, epoch_time.
  Возвращает: (model, history)

plot_history(history, title="")
  Два графика - ошибка и точность для train и val по эпохам, с вертикальной
  линией на лучшей эпохе.

show_predictions(model, data, targets, n=10)
  Показывает n случайных картинок из выборки: в заголовке — верная метка,
  крупной белой цифрой в углу — предсказание модели.

ensemble_predict(data, targets, batch_size=256)
  Ансамбль из пяти обученных моделей. Печатает точность
  каждой модели и ансамбля, возвращает тензор предсказаний ансамбля.
